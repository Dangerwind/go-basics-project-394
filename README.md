# Генератор и чекер паролей на Go

Учебный проект консольного приложения, которое умеет генерировать предсказуемые (воспроизводимые) пароли по заданным флагам и оценивать их сложность по пятибалльной шкале.

## Как запустить и что на выходе

Для запуска проекта выполните в терминале команду:

```bash
go run .
```

Программа сгенерирует несколько тестовых паролей с разной конфигурацией (включая проверку на отрицательную длину) и проверит пять строк на надежность. 

Вывод в консоли будет выглядеть так:

```text
fzxc0WG0
5vjehYzZEzZ0
vfJ0p2rH&j9#
lrfkqyuq

Слабый пароль (оценка 1 из 5)
Слабый пароль (оценка 2 из 5)
Средний пароль (оценка 3 из 5)
Надёжный пароль (оценка 4 из 5)
Очень надёжный пароль (оценка 5 из 5)
```

---

## Что внутри

### 1. Функция GeneratePassword
Собирает алфавит из настроек и выдает строку нужной длины.

```go
func GeneratePassword(length, seed int, useUppercase, useDigits, useSpecial bool) string
```

* **Наборы символов**: Строчные буквы (`a-z`) берутся всегда. ПРОПИСНЫЕ (`A-Z`), цифры (`0-9`) и спецсимволы (`!@#$%^&*`) дописываются, если передать `true` в соответствующие флаги.
* **Предсказуемый рандом**: За выбор символов отвечает простая формула `(16807 * number) % 2147483647`. Благодаря этому при одинаковом `seed` функция всегда выдает один и тот же пароль.
* **Защита**: Если передать длину `0` или меньше, функция не упадет, а просто вернет пустую строку `""`.

### 2. Функция CheckPassword
Проверяет строку по пяти критериям и начисляет по 1 баллу за каждый:
1. Длина от 8 символов.
2. Есть строчная буква.
3. Есть прописная буква.
4. Есть цифра.
5. Есть спецсимвол (`!@#$%^&*`).

На основе баллов выдает строгий вердикт в формате `"<Вердикт> пароль (оценка X из 5)"`:
* **0–2 балла** — Слабый
* **3 балла** — Средний
* **4 балла** — Надёжный
* **5 баллов** — Очень надёжный
