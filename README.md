# Консольный генератор и чекер паролей на Go

Инструмент на языке Go, состоящий из двух модулей: гибкого генератора безопасных паролей и системы оценки их криптостойкости. 

Приложение спроектировано без внешних зависимостей и использует детерминированный алгоритм генерации, что гарантирует воспроизводимость паролей при использовании одного и того же ключа инициализации (`seed`).

---

## Демонстрация работы

### Команда запуска
Для компиляции и запуска приложения «на лету» выполните команду в корневом каталоге проекта (там, где находятся файлы `.go`):

```bash
go run .
```

### Пример вывода программы
В консоли отобразится результат генерации четырех разных паролей (включая обработку крайних случаев с отрицательной длиной) и оценка надежности пяти тестовых строк:

```text
fzxc0WG0
5vjehYzZEzZ0
vfJ0p2rH&j9#
lrfkqyuq

Слабый пароль (оценка 1 из 5)
Слабый пароль (оценка 2 из 5)
Средний пароль (оценка 3 из 5)
Надёжный пароль (оценка 4 из 5)
Очень надёжный пароль (оценка 5 из 5)
```

## Функционал приложения

### 1. Генерация паролей (`GeneratePassword`)
Функция собирает алфавит на основе переданных флагов и генерирует строку заданной длины.

```go
func GeneratePassword(length, seed int, useUppercase, useDigits, useSpecial bool) string
```

* **Динамический алфавит**: Строчные буквы (`a-z`) включены всегда. Прописные (`A-Z`), цифры (`0-9`) и спецсимволы (`!@#$%^&*`) добавляются строго друг за другом при включении соответствующих флагов (`true`).
* **Воспроизводимость**: За генерацию отвечает встроенный линейный конгруэнтный алгоритм `NextRandom(number int) int`, работающий по формуле `(16807 * number) % 2147483647`. Это позволяет зафиксировать `seed` для получения одинаковых результатов при каждом запуске.
* **Обработка крайних случаев**: Если передан параметр `length <= 0`, функция корректно завершает работу без ошибок и возвращает пустую строку `""`.

### 2. Проверка надежности (`CheckPassword`)
Функция анализирует переданную строку по пяти независимым критериям, начисляя по 1 баллу за каждый:

1. Длина пароля составляет **8 и более символов**.
2. Присутствует хотя бы одна **строчная латинская буква** (`a-z`).
3. Присутствует хотя бы одна **ПРОПИСНАЯ латинская буква** (`A-Z`).
4. Присутствует хотя бы одна **цифра** (`0-9`).
5. Присутствует хотя бы один **спецсимвол** из набора `!@#$%^&*`.

#### Шкала оценивания:
* **0–2 балла** — `Слабый`
* **3 балла** — `Средний`
* **4 балла** — `Надёжный`
* **5 баллов** — `Очень надёжный`

Формат вывода строго фиксирован: `"<вердикт> пароль (оценка <баллы> из 5)"`.
